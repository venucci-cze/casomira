1. Program k časomíře s ESP8266 mikrokontrolérem. (V budoucnu možná ESP32-XX a to kvůli dvojici jáder které by mohly zajistit lepší přesnost, díky omezení sub procesů mimo main loop)
2. V Releses stačí stáhnout casomira.exe a updater.exe
3. casomira.exe hlavní program který čte, zapisuje, spravuje a zobrazuje data z mikrokontroleru v časomíře.
4. updater.exe je doprovodný program, který aktualituje program casomira.exe pomocí tlačítka "Kontrola aktualizací".
